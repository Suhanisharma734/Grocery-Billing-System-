# 🛒 Grocery Billing System

A desktop-based **Grocery Billing System** developed using **Java Swing**, **JDBC**, and **MySQL**. This application streamlines retail billing, inventory management, and customer receipt generation through an intuitive graphical user interface.

## ✨ Key Features
* **Billing & Receipt Generation:** Quickly add items to the cart, calculate subtotals, taxes/discounts, and generate itemized customer bills.
* **Inventory Management:** Add, update, view, and delete grocery products with real-time stock tracking in MySQL.
* **Database Integration:** Seamless CRUD operations powered by JDBC and MySQL.
* **User-Friendly GUI:** Built with Java Swing components for smooth navigation and fast checkout operations.

## 🛠️ Tech Stack
* **Frontend / GUI:** Java Swing & AWT
* **Backend:** Core Java (JDK)
* **Database:** MySQL
* **Connectivity:** JDBC (MySQL Connector/J)
